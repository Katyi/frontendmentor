# Frontend Mentor - Blog preview card

This is my solution to the Blog preview card challenge on Frontend Mentor.

## Overview

### The challenge

The challenge was to build a blog preview card and make it look as close to the provided design as possible.

Users should be able to see hover and focus states for interactive elements.

## My process

### Built with

* HTML5
* CSS3
* Flexbox
* CSS media queries
* Semantic HTML
* CSS pseudo-classes (`:hover`, `:focus-visible`)

### What I learned

While working on this project, I practiced building a responsive card layout with HTML and CSS.

I also learned how to implement hover and keyboard focus states for links using CSS pseudo-classes, without JavaScript.

### Continued development

I want to keep improving my CSS skills, especially responsive layouts, accessibility, and writing clean, maintainable code.
