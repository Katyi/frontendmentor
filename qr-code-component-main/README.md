# Frontend Mentor - QR code component

This is my solution to the [QR code component challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H).

## Overview

### The challenge

Build a QR code component that matches the provided design and works well on different screen sizes.

### My solution

I recreated the design using semantic HTML and CSS, focusing on responsive layout, spacing, typography, and alignment.

### Built with

* Semantic HTML5
* CSS
* Flexbox
* Responsive design

### What I learned

This project was mainly a refresher of my existing frontend skills. I practiced translating a design into code and adjusting the layout for different screen sizes.
